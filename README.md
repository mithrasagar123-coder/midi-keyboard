# MIDI Keypad

## Overview

A custom MIDI keypad with switches, sliders, rotary encoders, neopixels and capacitive touch keys. You can connect it to a computer music software and make sick beats :) 

I designed this for my Week 3 project of halflife, a 10-week program where you can design and build hardware projects free of cost!

## Parts
* Bourns Slide Potentiometers: analog faders
* Kailh Choc Low-Profile Switches!
* SK6812 MINI-E Neopixels: Cool RGB lighting!
* EC11 Rotary Encoders: spinny spinny knob!
* Capacitive Touch Keys!
* Custom keycaps!
